# Storefront monorepo

Every service of the storefront lives here.

| Directory | What it does |
|---|---|
| `billing/` | Subscriptions: trials, renewals, dunning and cancellation |
| `catalog/` | Product records and price lists |
| `notifications/` | Email templates and sending |
| `search/` | Query parsing and ranking |
| `shared/` | Helpers used by every service |
| `docs/` | Architecture notes |
